# Convert a Legacy `dicomtk::dicom_llm` Object to `dicom_ai_chat`

Convert a Legacy
[`dicomtk::dicom_llm`](https://lauyeehow1986-hub.github.io/dicomtk/reference/dicom_llm.html)
Object to `dicom_ai_chat`

## Usage

``` r
as_ellmer_chat(x)
```

## Arguments

- x:

  A `dicom_llm`, `dicom_ai_chat`, or `ellmer` `Chat` object.

## Value

A `"dicom_ai_chat"` object.
