# dicomtk.ai

AI Agents, Model Context Protocol (MCP) tooling, pluggable segmentation/uncertainty backends, clinical report NLP, RadLex/LOINC-RSNA protocol harmonisation, and DuckDB vector similarity search for `dicomtk`.

## Installation

```r
install.packages("dicomtk.ai", repos = c(
  "https://lauyeehow1986-hub.r-universe.dev",
  "https://cloud.r-project.org"
))
```
